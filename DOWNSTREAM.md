# Downstream Build Notice

This repository is a public downstream fork of the Proton Pass Android
source repository:

https://github.com/protonpass/android-pass

## Status

Builds produced from this fork are unofficial downstream builds.

They are not official Proton releases, are not signed by Proton, and are
not represented as being endorsed or distributed by Proton.

The intended downstream Android build target is the Proton Pass
`nogmsProd` variant.

## Downstream Signing

APKs produced for this downstream update channel may be signed with a
persistent signing key controlled by the maintainer of this fork.

That signing identity is independent of Proton's signing infrastructure.
A downstream signing certificate must not be interpreted as a Proton
signature or endorsement.

## Build Provenance

Each downstream APK should be accompanied by enough provenance to identify
the exact source and build that produced it, including where available:

- upstream source commit SHA
- downstream source commit SHA
- application version name and version code
- build workflow revision
- APK SHA-256 digest
- signing certificate SHA-256 digest
- Android build variant

The signing private key itself must never be committed to this repository.
